## ✨ Sobre o repositório

Este repositório reúne atividades, exercícios e projetos desenvolvidos durante as aulas de **Front-End em 2026**.

O objetivo é registrar minha evolução na programação, praticar os conhecimentos adquiridos em aula e desenvolver projetos utilizando diferentes tecnologias e recursos do desenvolvimento web.

## 📂 Organização

| Pasta | Descrição |
|---|---|
| 📘 `Aula 01 - Revisão` | Atividades de revisão e prática dos conteúdos |
| 🔢 `JogoNumeroSecreto` | Projeto de jogo do número secreto |
| 📝 `aula02_exercicio` | Exercícios desenvolvidos durante as aulas |
| ⚛️ `aulas_react` | Atividades e práticas utilizando React |

## 🎯 Objetivos

- Praticar os conceitos de desenvolvimento Front-End.
- Aprimorar a lógica de programação.
- Desenvolver páginas e aplicações interativas.
- Aprender e aplicar React.
- Organizar projetos utilizando Git e GitHub.
- Registrar minha evolução como desenvolvedora.

## 🌱 Minha evolução

Cada pasta representa uma etapa do aprendizado, reunindo exercícios e projetos que contribuem para o desenvolvimento das minhas habilidades na programação.

Este repositório está em constante atualização, acompanhando as atividades e os novos conhecimentos adquiridos ao longo de 2026.
